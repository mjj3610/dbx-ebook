## 一、新增功能

1. **多格式解析内核**（18 种）
   - 电子书：EPUB/EPUB3、PDF、MOBI、AZW、AZW3、PRC(PDB)
   - 文本类：TXT（自动识别 UTF-8 / UTF-16 / GB18030）、Markdown、RTF、HTML/XHTML/HTM
   - 办公文档：DOCX、ODT
   - 其他：FB2、FBZ
   - 漫画：CBZ（ZIP）、CBT（TAR）
2. **阅读器**：单页 / 双页（CSS 多栏）/ 滚动三种模式；字号、行距、页边距、三字体、四主题；目录；进度记忆与跳转；键盘翻页（←/→/PageUp/PageDown/空格）；PDF 缩放。
3. **听书**：Web Speech 逐句合成，自动续读下一章，正文跟随高亮，可调语速 / 音调 / 音色。
4. **翻译**：选中即译，支持 OpenAI 兼容接口与 LibreTranslate，结果写入 IndexedDB 缓存。
5. **高亮笔记**：四色高亮、批注、按章节聚合的笔记侧栏、点击回跳、Markdown 导出。
6. **备份与同步**：本地导出（纯数据 / 含书籍文件）、导入恢复、WebDAV 上传下载与连通性测试。
7. **i18n**：简体中文 / English，文案全部资源化。
8. **宿主集成**：跟随 DBX 宿主的深浅色外观与界面语言；复制走宿主剪贴板；宿主缺失时自动降级为独立运行。
9. **存储位置可选**：书架「存储位置」可切换三种模式——自动（IndexedDB）、**本地文件夹**（目录内生成 `library.json` 与 `books/`，原始书籍文件直接落盘，可跨会话、可整体拷贝迁移）、仅本次会话；切换时自动把当前书库迁移到新位置。

## 二、优化项

- 单页最大正文宽度限制为 820px 并居中，避免宽屏单行过长；滚动模式与分页模式共用同一栏宽常量。
- 阅读区增加「纸面」层次（纸色背景 + 轻阴影），与工具栏和底色形成区分，不影响分页尺寸计算。
- 顶栏与底部进度条改为常驻（原自动隐藏会导致返回按钮不可点）。
- 封面归一化：任意来源封面统一压缩为 ≤320px 的 JPEG dataURL，控制 IndexedDB 体积。
- 解析结果内存缓存上限 2 本，淘汰时释放 blob URL，避免长时间使用内存膨胀。
- UI 颜色全部改为语义令牌（`--c-panel` / `--c-subtle` / `--c-hover` 等），深色令牌集中在 `html[data-appearance='dark']` 下一处覆盖，组件内不再硬编码浅色值。

## 三、修复项

| 编号 | 问题 | 处理 |
| --- | --- | --- |
| F-01 | PDF 二次打开报 `detached ArrayBuffer` | pdf.js 会转移数据到 Worker，改为传入副本 |
| F-02 | PDF 调用 `getPage` 报 `Cannot read from private field` | pdf.js 实例存入 `shallowRef`，避免被 Vue 响应式代理破坏私有字段 |
| F-03 | PDF 文本层出现重影（透明文字变可见） | 动态创建的节点需用 `:deep()` 穿透 scoped 样式 |
| F-04 | Shadow DOM 内选中后浮条不出现 | 不再依赖 `selection.isCollapsed`，改用起止偏移判定 |
| F-05 | 设置面板部分标签显示为 `reader.fontSize` 等原始键 | 修正被批量替换破坏的 i18n 键名 |
| F-06 | 导入时清空 input.value 导致文件引用被回收 | 改为打开选择框前清空；读取失败时给出「无法读取文件内容，请重新选择该文件」 |
| F-07 | 宿主下发的语言 / 深色外观被重置为默认值 | `App.vue` 挂载时重复调用 `loadSettings()`，覆盖了 `bootstrap()` 套用的宿主默认值；移除该重复调用 |
| F-08 | 分页正文贴左，820px 栏宽未居中 | 分页容器是 Shadow DOM host，被解析为 `display: inline` 使 `margin: 0 auto` 失效；显式声明 `display: block`，实测正文左边界由 48px 修正为 230px（1280 视口） |
| F-09 | 插件在宿主沙箱内**白屏** | 宿主 CSP 为 `default-src 'none'; script-src 'unsafe-inline' blob:` 且只内联 `<script src>`，`manualChunks` 拆出的 `pdf-*` / `zip-*` 分块无法内联 → 关闭代码分割，改为单文件 bundle |
| F-10 | PDF worker 无法加载 | 独立 worker 文件既被 CSP 拒绝也无法 fetch（`connect-src 'none'`）；改为 `?raw` 内联源码 + `URL.createObjectURL(Blob)` |
| F-11 | 宿主切换深色主题，插件不跟随 | 宿主只更新 `html[data-dbx-theme]`，`dbxPlugin.theme.appearance` 保持注入时的旧值；改为以 DOM 属性为准，并加 `MutationObserver` 监听 |
| F-12 | 沙箱内 IndexedDB 被禁，弹出英文 `SecurityError` | 增加存储能力探测，失败时显示中文提示条并跳过书架查询，不再弹底层报错 |
| F-13 | 沙箱内**书籍与笔记完全无法保存**，插件实际不可用 | 存储层改为可降级：IndexedDB 优先，失败自动切内存库（`MemoryBackend`），导入 / 阅读 / 高亮 / 备份导出全流程可用；`storagePersistent()` 让界面如实提示「本次会话有效」并给出备份导出入口 |
| F-14 | 内存库仍无法真正保留数据 | 新增 `DirectoryBackend`（`src/core/fs.ts` + `db.ts`）：用户选择本地目录后，书库索引写入 `library.json`、原始文件写入 `books/`，真正落盘 |
| F-15 | 沙箱内点击「选择文件夹」报英文 `SecurityError`（Sandboxed documents aren't allowed to show a file picker） | 前置检测 `origin === 'null'`，把目录模式标记为「沙箱限制」并解释原因；同时把 `SecurityError` 转换为可读中文提示 |

| 仓库 | 主键 | 索引 | 说明 |

## 七、部署流程

```bash
# 1) 安装依赖并构建（产物输出到 ui/）
npm ci
npm run build

# 2) 打包（调用官方 CLI，生成 .dbxp 与 artifact.json）
npm run pack
# 等价于：npx dbx-plugin package . --output-dir release

# 3) 校验产物
ls release/
#   com.csisolar.ebook-1.0.0-universal.dbxp
#   com.csisolar.ebook-1.0.0-universal.artifact.json
unzip -l release/com.csisolar.ebook-1.0.0-universal.dbxp
#   应包含 manifest.json / assets/plugin.svg / ui/index.html / ui/assets/* / checksums.json
shasum -a 256 release/com.csisolar.ebook-1.0.0-universal.dbxp   # 与 artifact.json 的 sha256 一致

# 4) 安装到 DBX
#    由宿主「安装本地插件」选择 .dbxp；或提交到仓库由运营方用 dbx-plugin keygen 的密钥签名后分发。
#    安装后确认：图标显示、点开进入书架、浅/深色跟随宿主、控制台无报错。
```

> `.dbxp` 为**未签名评审候选**，官方商店或自建仓库需另行签名，这是 CLI 的既定流程，不是打包失败。

```bash
# Windows
netstat -ano | findstr :4173 && taskkill /PID <PID> /F
# Linux / macOS
lsof -i:4173 | awk 'NR>1{print $2}' | xargs -r kill -9
```

## 九、回滚方案

1. 在宿主插件列表中卸载 `电子书阅读器`。
2. 重新安装上一版本 `.dbxp`（当前为首版，无历史版本）。
3. 用户数据在 IndexedDB 与 localStorage 中，卸载插件不会自动清除；如需彻底清空，在插件内删除全部书籍或清除该站点存储。
4. 若仅需回退配置：设置面板提供「恢复默认」入口（阅读设置）。

## 十、注意事项

- 首次导入大文件（>200 MB）会有解析等待，界面显示导入进度；单文件上限 512 MB。
- HUFF/CDIC 压缩的 AZW3、CBR/CB7、带 DRM 的书籍无法解析，均会给出明确提示与转换建议。
- 翻译与网盘同步依赖外部接口，部署环境需允许出网；WebDAV 服务端需开启 CORS（坚果云已支持）。
- 听书依赖系统语音包，无中文语音时会回退到默认语音。

## 十一、规范改造对照（对照 dbxio.com 插件开发文档）

改造前按通用插件规范搭建（自写 zip 打包），经与官方文档核对**不符合** DBX 插件规范，本版本已全部改造并通过官方 CLI 实包验证。

| 项 | 改造前 | 改造后 |
| --- | --- | --- |
| 清单 | 通用格式（`id: dbx-ebook`、`main` / `entry` / `activationEvents`） | `manifest.json` v1：`manifest_version`、`engines.host_api`、`entrypoints.ui.root/entry`、`contributions`、`localizations` |
| 打包配置 | 无 | `dbx-plugin.toml`：`schema_version = 1`、`[package].include = ["assets","ui"]`、`[dev].ui_build` |
| 构建输出 | `dist/` | `ui/`，与 `entrypoints.ui.root` 一致；`base: './'` 保证相对路径 |
| 图标 | `icon.png` + `public/icon.svg` | `assets/plugin.svg`，清单 `icon` 指向该文件 |
| 安装包 | 自写脚本打 `zip` | `dbx-plugin package` 生成 `.dbxp` + `.artifact.json`（附 `checksums.json`，未签名评审候选） |
| 宿主能力 | 未接入 | `src/core/host.ts`：`ready` / `locale` / `theme.appearance` / `copy` / `onInit`，宿主缺失时全量降级 |
| 深色主题 | 不支持 | 语义色令牌 + `html[data-appearance='dark']` / `html[data-dbx-theme='dark']` 双选择器 |

> 出网权限按域名逐条声明（`host.network:<origin>:<port>`，上限 8 条），当前仅声明翻译（OpenAI、LibreTranslate）与 WebDAV（坚果云）三个域名；新增服务商时需同步修改 `manifest.json`，否则宿主会拦截请求。


## 十二、宿主沙箱适配（实测结论）

用官方 `dbx-plugin dev` 起真实宿主后，插件运行在 `sandbox="allow-scripts"` 的 iframe 中，实测约束与应对如下：

| 约束 | 实测表现 | 应对 |
| --- | --- | --- |
| 脚本加载 | CSP `default-src 'none'; script-src 'unsafe-inline' blob:`；宿主只把 `<script src>` 与样式表内联进文档，无法内联额外 chunk | 单文件 bundle（关闭 `manualChunks`、`modulePreload`、`cssCodeSplit`） |
| 资源获取 | `connect-src 'none'`，`fetch` / XHR 一律被拒 | PDF worker 改为内联 blob；翻译 / WebDAV 依赖正式宿主的 `host.network` 白名单 |
| 主题 | 宿主切主题只改 `html[data-dbx-theme]`，不改桥接对象 | 以 DOM 属性为准 + `MutationObserver`；CSS 双选择器匹配 |
| 存储 | `origin === 'null'`，`localStorage` / `indexedDB` 抛 `SecurityError`，桥接无存储 API（仅 `backend.*` / `host.getContext` / `ui.readAsset`） | 三后端可切换：IndexedDB / 本地文件夹 / 内存；沙箱内自动降级为内存并如实提示 |
| 文件夹选择 | `showDirectoryPicker` 存在，但报 `Sandboxed documents aren't allowed to show a file picker` | 前置检测并标记「沙箱限制」；非沙箱环境（浏览器直接打开、或宿主未沙箱化）可选目录并真正落盘 |

**尚未在真实客户端验证的部分**：书籍持久化与出网请求。dev 宿主不开放存储与网络，只能验证 UI 层；安装到 DBX 客户端后需确认 `host.network` 白名单生效，以及宿主是否为插件提供持久化能力（若不提供，需改用宿主文件系统 API 或后端 sidecar 存储，属于下一版改造项）。
