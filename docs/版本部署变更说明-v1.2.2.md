## 一、本版解决的两个反馈

### 1. 「单页和双页怎么翻页」——原来没有可见的翻页入口

| 阅读器 | 修复前 | 修复后 |
| --- | --- | --- |
| PDF | **完全没有翻页 UI**，只能靠键盘 | 视口左右中部一对圆形 `‹` `›` 按钮；另支持触屏左右滑动 |
| 文字（EPUB / TXT / FB2 / DOCX / MD …） | 只有鼠标悬停时才浮现的透明点击热区（`.edge`），不看提示根本发现不了 | 同款圆形按钮；到首章 / 末页自动置灰禁用 |
| 漫画（CBZ / CBR） | 同样只有透明热区 | 同款按钮（深色配色） |

现在可用的翻页方式共四种：

- 点视口左右的圆形按钮（新增，最直观）
- 键盘 `←` `→` `PageUp` `PageDown` `空格`
- 手机上左右滑动（新增，横向位移 ≥ 60px 且明显大于纵向时才触发，避免和长按选词打架）
- 滚动模式下按滚轮 / 触控板

按钮只在分页 / 双页模式出现；滚动模式下隐藏（那里靠滚动，翻页按钮没有意义）。

### 2. 「PDF 名称导入后变化了」——书名被内嵌元数据顶掉

原因有两层，都是「以谁为准」的选择错了：

1. `parsePdf` 优先取 PDF 的 `/Info` 里的 `Title`。而用 Word / WPS 导出 PDF 时，
   文件属性里往往还留着**旧文档标题**（例如 `Microsoft Word - 法律翻译—服务合同.docx`）——
   于是导入后书架上显示的是这个旧名字，不是你的文件名。
2. `titleFromFilename()` 会把文件名里的 `_` 替换成空格，即使走文件名分支，显示出来也和磁盘上不一致。

现在的规则：

- **文件名优先**。用户在磁盘上看到的是文件名，书架就应该显示它，一个字都不改（只去掉扩展名）。
- 只有当文件名**本身没有信息量**时才退回内嵌标题：纯数字（`001.pdf`）、≥8 位哈希名、
  或 `untitled / document / doc / book / ebook / scan / image / img / file / new / 未命名 / 无标题 / 新建 / 文档 / 扫描 / 图片 / 文件`（可带序号）。
- 退回内嵌标题前先清洗：去掉 `Microsoft Word - ` / `Microsoft PowerPoint - ` 之类前缀与 `.docx` / `.pdf` 后缀。

## 二、顺带修掉的硬问题：双页模式其实一直只显示一页

这个问题是排查「怎么翻页」时发现的，比按钮缺失更严重——两层 bug 叠在一起：

1. **双页判定自我循环**：`perView` 依赖 `pageWidth`，而 `pageWidth` 又按 `perView` 算，
   「按单页算宽 → 两页放不下 → 退回单页」永远成立，双页形同摆设。改为只看容器宽度。
2. **宽度算式少扣内边距**：修好判定后仍然只看到一页——`616×2 + 16 + 48 = 1296 > 1280`，
   `.pages` 的 `flex-wrap: wrap` 把第二页换行到了下一屏（DOM 里两个 616px 的页面都在，
   视觉上就是「一页 + 一大片空白」）。现在精确扣除左右内边距，并改成 `flex-wrap: nowrap`，
   宁可横向滚动也绝不换行。

配套改动：

- 视口宽度改为响应式（`ResizeObserver`，差值 < 2px 忽略以避免滚动条抖动引起重绘循环），
  窗口缩放后页码、页宽、双页与否都会重算；
- 翻页时清掉已卸载页面的 DOM 引用，避免继续往脱离文档的 canvas 上绘制。

实测 1280 宽视口：双页两页落在 `[24..632]` 与 `[648..1256]`，`scrollWidth == clientWidth == 1280`（无横向溢出），两个 canvas 均为 608×782 且已绘制。

## 四、部署步骤

1. 关闭正在运行的插件页面（旧 bundle 会被缓存，务必重新加载）。
2. 用 `release/com.mjj3610.ebook-1.2.2-windows-x64.dbxp` 覆盖安装（同 id 升级，书库不受影响）。
3. 打开任意一本书，切到「双页」：应看到第 1、2 页并排，左右各有一个圆形箭头按钮。
4. 之前导入的 PDF 若书名仍是旧标题：那是入库时写进 `library.json` 的历史值，
   **删掉重新导入**即可按文件名入库（本版只影响新导入的书）。

## 五、已知限制

- 双页模式按「Fit Width」铺满视口宽度，超高页面仍需上下滚动；不做自动缩放适配整页高度。
- 双页永远是「左奇右偶」的固定配对（1-2、3-4…），不支持封面单独成页的排版习惯。
- 触屏翻页只认左右滑动，不做双指缩放（缩放走工具栏的 100% 下拉）。
- 跨平台发包：本包只含 `bin/windows-x64/backend.exe`；macOS / Linux 由 CI 各自构建。
- 其余限制（加密 PDF、扫描版 OCR、AZW3 的 HUFF/CDIC、未内嵌字体的字形差异）同 v1.2.1，均有明确提示。
