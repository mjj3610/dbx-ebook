# v1.2.6 变更说明

> 基线：v1.2.5（`62a93cf`）→ 本版 `1.2.6`
> 主题：修掉「PDF 里加不了高亮与笔记」，并让 PDF 的高亮真正看得见。

---

## 1. 用户报告

截图：PDF 阅读界面停在第 7 页（「三、重要工作推进—承揽商监管」表格页），右侧笔记面板空空如也，底栏提示「选中正文文字即可高亮」；文字**怎么选都没有浮条**，笔记加不进去。

同类现象：以前存过的高亮，重新打开这本书也不见了。

## 2. 根因

`src/core/render.ts` 的 `collectText()` 负责把容器里的文字收成一条文本流，是选区、高亮、引文定位三件事的共同底座：

```ts
const container = root.querySelector('.book')
```

而 PDF 阅读器的文本层元素**自己**就带 `.book` 类（`<div class="text-layer book" />`）——`querySelector` 只找子孙、**不匹配自身**，于是 `container` 恒为 `null`，`collectText()` 永远返回 `{ nodes: [], text: '' }`。

连锁后果全部指向同一处：

| 下游 | 表现 |
| --- | --- |
| `readSelection()` | `end <= start` → 永远返回 `null` → `onSelection(null)` → 浮条不出现 |
| `applyNotes()` / `wrapQuote()` | 空文本里找不到引文 → 老高亮一条都画不出来 |
| 笔记面板 | 没有任何 note 被写入，所以是空的 |

EPUB / TXT 不受影响：它们的 root 是 ShadowRoot，正文确实在**子节点**的 `.book` 里，`querySelector` 能命中——这也是为什么只有 PDF 出问题。

## 3. 修复

**① `collectText()` 兼容「根节点自身就是容器」**（`src/core/render.ts`）

```ts
const self = root as Partial<Element>
const container: ParentNode | null =
  typeof self.classList?.contains === 'function' && self.classList.contains('book')
    ? (root as ParentNode)
    : root.querySelector('.book')
```

判定放在 `querySelector` 之前，两条路径都成立：文字流阅读器仍走 ShadowRoot → `.book`，PDF 直接把文本层当容器。

**② 高亮样式抽成公共生成器**（`src/core/render.ts`）

```ts
export function buildMarkCss(prefix: string, textColor = 'inherit'): string
```

`buildBookCss` 改为 `buildMarkCss('.book')`，配色只有一处定义，不再两套各写一遍。

**③ PDF 挂载时注入透明文本层专用样式表**（`src/components/reader/PdfReader.vue`）

PDF 文本层的字是 `color: transparent`（真字画在 canvas 上），只写背景色看不出任何变化——必须显式把文字保持透明、把背景给足：

```ts
markStyleEl = document.createElement('style')
markStyleEl.dataset.dbxMark = 'pdf'
markStyleEl.textContent = buildMarkCss('.text-layer', 'transparent')
document.head.appendChild(markStyleEl)   // onMounted
markStyleEl?.remove()                    // onBeforeUnmount
```

宿主 CSP 是 `style-src 'unsafe-inline' blob:`，注入样式表不受影响（已在真实宿主里实测）。

### 附：测试脚本自身的一个坑

`host-note.mjs` 第一版把 `frame.evaluate` 里的 `getBoundingClientRect()`（**iframe 内**坐标）直接喂给 `page.mouse`（**主页面**坐标），拖拽点整体偏移到宿主外壳上，选中的其实是宿主 UI 的文字，出现假阴性。现已统一改用 `locator.boundingBox()`（Playwright 已换算到主页面坐标系）。凡是「在 iframe 里拖拽」的脚本都要注意这一条。

## 5. 怎么加高亮 / 笔记（操作路径）

1. 打开 PDF，**按住左键拖过要标记的文字**（跨行、跨单元格都可以，同一页内）。
2. 抬手后文字上方浮出操作条：**四个色点** = 直接高亮；**批注** / **翻译** / **复制**。
3. 点色点 → 立即生成高亮（颜色写进笔记，无需再确认）。
4. 点「批注」→ 弹窗里写批注正文、选颜色 → 保存。
5. 右上角**笔记按钮**打开面板：按章节（PDF 按页）分组，显示引文 + 批注 + 时间；点条目跳回原文位置，垃圾桶删除（二次确认）。

已知限制：**跨页拖选**（从第 7 页拖到第 8 页）目前不会出浮条——选区两端落在两个独立的文本层里，`readSelection` 会判为无效。需要标记跨页内容时，请分两次选。扫描件（无文本层）无法选中，只能用截图类工具。
